# Preferencias del proyecto

- El nombre de la cumpleañera es Alison. Usarlo en los textos y metadatos.
- Usar iconos SVG integrados con etiquetas accesibles para los controles; evitar emojis o glifos decorativos que dependan de las fuentes del dispositivo.
- El primer toque en el fondo o texto de la portada activa el audio. El control de sonido permite activarlo o silenciarlo; los toques posteriores no deben anular un silencio elegido. Abrir la invitación detiene el video. Con movimiento reducido, conservar el fotograma estático incluso cuando se escucha el audio.
